# 产品方案理解概述

## 产品定位与价值
- **愿景**：通过数据量化和智能洞察帮助用户塑造健康的短视频使用习惯，并为家长和研究者提供透明、合规的参考数据。
- **核心价值主张**：
  - 面向个人用户：提供多维度的使用报告、目标管理和正向反馈，帮助识别时间黑洞。
  - 面向家长与管理者：在严格隐私保护前提下提供设备使用透明度。
  - 面向研究机构：在获得授权和充分脱敏后提供群体趋势洞察。

## 目标用户与关键场景
- 目标人群：自律意识强、关注时间管理的年轻人群；需要了解孩子或团队使用情况的监护人/管理者；自我量化爱好者。
- 典型场景涵盖日常复盘、目标管理、趋势观察与家长监护，强调从使用统计到行为调整的闭环。

## 核心功能拆解
1. **时间追踪**：
   - 使用 Android `UsageStatsManager` 做到秒级别的进入/退出记录。
   - 需要解决后台存活、权限申请和电池优化兼容问题。
2. **视频类型识别**：
   - 核心挑战，分为粗粒度的网络流量分析与可选的本地多模态精细识别。
   - 多模态方案整合 OCR/ASR 文本、音频特征、视觉低层特征，通过轻量模型实现隐私友好分类。
3. **数据聚合与可视化**：
   - 以日/周/月维度生成趋势曲线、类型分布、应用使用明细。
   - 自动生成图文周报/月报，提供亮点总结和建议。
4. **辅助功能**：
   - 目标设定与提醒、专注模式、成就系统、数据导出与云同步。

## 技术架构理解
- **移动端为核心**：本地服务负责使用统计、分类识别与可视化展示，SQLite 持久化数据。
- **可选云端**：在用户授权下进行加密同步，后端基于 Node.js + MongoDB 提供用户管理与聚合分析。
- **隐私策略**：遵循数据最小化、权限透明、匿名化存储及合规政策，确保原始内容留在本地。

## UI/UX 与体验重点
- 首页仪表盘突出今日总时长、目标进度与类型分布。
- 详情页面支持切换周期、查看应用级别明细。
- 目标和成就页面注重正向激励与个性化配置。

## 商业模式与迭代规划
- **免费版**：提供核心统计与目标管理，快速获取用户。
- **Pro 订阅**：解锁高级分析、历史数据、成就、云同步和家庭监护。
- **开发路线**：
  - MVP 聚焦时间追踪、基础分类、图表与提醒。
  - 后续迭代加强识别精度、专注模式、成就与同步。
  - 长期扩展 iOS 版本与家庭/团队场景。

## 风险与应对策略
- **技术适配**：持续适配安卓厂商策略，提供用户指引。
- **隐私信任**：保持透明、合规，强化本地处理优势。
- **竞争差异化**：突出跨平台统计与深度类型洞察。
- **商业化**：确保免费版价值，精细设计付费权益与价格。

## 后续工作重点
- 明确 MVP 功能边界与数据管线详细设计。
- 制定多模态分类引擎的技术验证计划与模型轻量化方案。
- 打磨核心仪表盘与提醒体验，确保数据准确、反馈及时。
- 建立隐私与权限指引文案，准备合规材料。
