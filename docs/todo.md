# 开发任务 TODO 清单

> 基于《技术方案》第 2.2 节功能模块 & 任务拆解，按模块列出可执行的工作项，并在每项前设置状态占位符，供团队在规划与执行时更新。

## 状态约定
- [ ] 未开始
- [~] 进行中
- [x] 已完成

---

## 1. 时间追踪子系统
- [x] T1 使用情况事件采集服务（UsageStats + Accessibility 组合），输出统一的 App Session 数据。
  - **KPI**：Session 识别准确率 ≥95%；漏报率 <2%；重报率 <1%；事件延迟（App 退出到 Session 写入）≤2s（p95）。
  - **Steps**：构造频繁切换、锁屏/解锁、后台清理三类场景各 30 次，核对人工计时、系统数字健康和采集服务记录。
  - **Artifacts**：对比报告 CSV、日志样本、测试脚本。
- [~] T2 后台保活策略实现（前台服务 + 电池优化引导文案）。
  - **KPI**：前台服务 24h 存活率 ≥99%（模拟器 + 3 台真机）；电池白名单引导点击转化率 ≥85%。
  - **Steps**：执行夜间 8h 保活回归，记录唤醒/重启次数及丢失事件数。
  - **Artifacts**：保活监控面板截图、引导漏斗数据。
- [x] T3 Session 归并与异常修复逻辑（跨日、重叠、崩溃恢复）。
  - **KPI**：跨日/重叠修复正确率 ≥98%；崩溃恢复后数据丢失为 0；归并作业耗时 ≤300ms（p95，单日 1k 事件）。
  - **Steps**：注入重叠、跨日、宕机样例各 100 组，对比修复前后数据。
  - **Artifacts**：单元测试报告、异常样例库。

## 2. 内容信号采集
- [ ] C1 短视频 App 文本信号采集（标题/标签/评论摘要），含无障碍策略配置。
  - **KPI**：抖音/快手/B 站抓取成功率 ≥90%；页面结构变更后热更新 ≤24h；单次抓取耗时 ≤200ms（p95）。
  - **Steps**：每平台随机浏览 100 条内容，核对字段完整性与时序。
  - **Artifacts**：采集成功率报表、解析规则库（版本化）。
- [ ] C2 本地脱敏处理流程（去除昵称、ID 等 PII）。
  - **KPI**：PII 识别与脱敏命中率 ≥99%；误脱敏 <1%；明文 PII 遗留为 0（全量扫描）。
  - **Steps**：使用包含昵称、ID、URL 的样本 200 条跑脱敏流程，结合正则与词典交叉校验。
  - **Artifacts**：脱敏规则与词典、扫描报告。
- [ ] C3 内容快照入库并与 Session 建立关联。
  - **KPI**：孤儿快照为 0；关联正确率 100%（抽样 500 条）；入库失败重试成功率 100%（网络/DB 故障模拟）。
  - **Steps**：注入数据库锁、磁盘写满等故障，观察队列重试表现。
  - **Artifacts**：ERD 图、DAO 覆盖率报告、死信队列日志。

## 3. 文本驱动分类引擎
- [ ] L1 Prompt 模板与分类标签定义（多平台统一格式）。
  - **KPI**：内部标注集 F1 ≥0.75（≥1k 样本）；类别最小支持度 ≥5%；模板更新后 F1 不下降（差值 ≤0.02）。
  - **Steps**：执行 5 折交叉验证，审阅混淆矩阵并给出标签合并建议。
  - **Artifacts**：Prompt 版本库、标签手册、混淆矩阵。
- [ ] L2 LLM 推理提供方选型与 SDK 接入（本地优先、云端备选）。
  - **KPI**：端侧推理时延 ≤2s（p95）；离线可用率 100%；云端降级回退成功率 100%。
  - **Steps**：执行飞行模式、限带宽（128kbps）压力测试 500 次。
  - **Artifacts**：Provider 切换策略文档、时延分布图。
- [ ] L3 分类任务调度与失败重试机制。
  - **KPI**：任务吞吐 ≥10 jobs/s；失败重试上限 3 次后入死信率 100%；重复文本缓存命中率 ≥40%。
  - **Steps**：批量 5k 样本入队，注入 API 500 与超时故障。
  - **Artifacts**：队列监控面板、死信分析报告。
- [ ] L4 置信度评估与人工校正接口（供后续模型迭代）。
  - **KPI**：低置信度复审后净 F1 提升 ≥0.03；人工校正到模型再训练闭环时延 ≤7 天。
  - **Steps**：标注 200 条低置信度样本，评估复审前后 F1 变化。
  - **Artifacts**：审阅工具 Demo、再训练 Changelog。

## 4. 数据处理与存储
- [ ] D1 日/周聚合作业与仪表盘数据准备流程。
  - **KPI**：聚合与原始事件一致性误差 <1%；单次聚合作业 ≤500ms（p95，日 10k 事件）。
  - **Steps**：随机抽取 50 日样本进行一致性快照比对。
  - **Artifacts**：一致性快照脚本、差异报告。
- [ ] D2 SQLite Schema & DAO 层实现（含加密方案）。
  - **KPI**：DAO 单元测试覆盖率 ≥80%；迁移失败率 0（两次版本升级）；敏感字段 AES-256 加密率 100%。
  - **Steps**：执行 v1→v2→v3 升级链测试，并演练密钥轮换。
  - **Artifacts**：Room Schema JSON、迁移脚本、密钥管理文档。
- [ ] D3 数据导出接口（CSV/PDF 钩子，预留给 P1）。
  - **KPI**：7/30 天导出成功率 100%；大型导出（1e5 行）完成时间 ≤5s（p95）；导出文件 PII 扫描 100% 通过。
  - **Steps**：生成极限数据集导出并运行脱敏扫描器。
  - **Artifacts**：导出样例、数据字典、隐私自检清单。

## 5. 目标与提醒系统
- [ ] G1 目标配置 UI/逻辑（全局与分类级）。
  - **KPI**：配置保存成功率 100%；冲突解析正确率 100%；重启后配置生效验证 100%。
  - **Steps**：构造 6 组包含工作日/周末阈值冲突的用例回归测试。
  - **Artifacts**：用例表、状态机图。
- [ ] G2 目标进度评估引擎（实时累计对比）。
  - **KPI**：实时累计误差 <1 分钟/日；评估周期 ≤1s（p95）。
  - **Steps**：回放 1 天（1k 事件）数据流，比较累计值。
  - **Artifacts**：回放脚本、误差曲线。
- [ ] G3 通知提醒调度与安卓通知策略适配。
  - **KPI**：“剩余 10 分钟”通知必达率 >95%；重复通知抑制成功率 100%；首次通知点击跳转正确率 100%。
  - **Steps**：覆盖 Doze/免打扰/前后台 12 组合场景进行触发回归。
  - **Artifacts**：通知事件日志、点击路径录屏。

## 6. 可视化与报告
- [ ] V1 仪表盘页（今日总时长、目标进度环、类型饼图）。
  - **KPI**：首屏渲染 <300ms（p95，已有缓存）；数据一致性抽检 100%；帧率 ≥55fps（90 分位）。
  - **Steps**：执行冷启动/热启动各 100 次，并与数据库快照比对。
  - **Artifacts**：性能分析报告、UI 快照测试结果。
- [ ] V2 趋势页（可切换日/周/月折线图 + App 明细列表）。
  - **KPI**：视图切换响应 ≤200ms（p95）；明细分页滚动掉帧 ≤5%。
  - **Steps**：在 30/180 天数据集下进行交互压力测试。
  - **Artifacts**：交互录屏、性能日志。
- [ ] V3 周报/月报生成器（图文摘要 + 建议模板）。
  - **KPI**：生成时延 ≤1s（p95）；模板国际化覆盖中/英 100%；指标与仪表盘一致性 100%。
  - **Steps**：随机 20 周数据对齐校验，并执行语言切换回归。
  - **Artifacts**：报告样例（PDF/JSON）、模板单测结果。

## 7. 隐私与权限合规
- [ ] P1 权限申请引导、用户授权记录与可撤销机制。
  - **KPI**：首次授权完成率 ≥85%；撤销后功能自动降级覆盖 100%；权限状态心跳异常告警延迟 ≤5 分钟。
  - **Steps**：执行授权/撤销/再授权三轮操作，验证功能降级与提示。
  - **Artifacts**：权限漏斗报表、心跳告警截图。
- [ ] P2 本地数据加密方案落地（SQLCipher/Keystore 结合）。
  - **KPI**：明文扫描 0 命中；密钥泄漏检查 0 命中；解密失败回退成功率 100%。
  - **Steps**：执行静态扫描、动态抓包，并模拟密钥丢失场景。
  - **Artifacts**：合规自评表、渗透测试简报。
- [ ] P3 隐私政策文档与 LLM 调用审计日志。
  - **KPI**：隐私政策与实际采集项一致性核对 100%；LLM 调用日志覆盖率 100%（时间、Provider、token 数、脱敏哈希）。
  - **Steps**：依据数据最小化清单逐项核对，抽样 100 次调用检查日志。
  - **Artifacts**：隐私清单、审计日志样本。

## 8. 工程与运维支撑
- [ ] E1 模块化项目结构搭建（核心服务/数据/UI/推理）。
  - **KPI**：模块边界循环依赖 0；公共 API 次要版本升级无破坏 100%。
  - **Steps**：运行静态依赖图检查，并演练一次小版本升级。
  - **Artifacts**：架构图、依赖检查报告。
- [ ] E2 自动化测试框架（单元、UI、端到端数据一致性）。
  - **KPI**：单元覆盖 ≥70%，核心模块 ≥80%；UI 自动化覆盖 3 条关键用户路径；端到端一致性回归 100%。
  - **Steps**：CI 执行全套测试，并注入 1 天事件流完成端到端对账。
  - **Artifacts**：CI 报告、覆盖率报表、E2E 对账脚本。
- [ ] E3 Crash 与性能监控接入（Firebase Crashlytics / Sentry 等）。
  - **KPI**：崩溃率 <1%；冷启动 <1.5s（p95）；ANR <0.3%；关键指标均有 Dashboard。
  - **Steps**：灰度运行 1 周收集指标，并注入卡顿/崩溃用例验证告警。
  - **Artifacts**：监控面板截图、告警策略清单。

---

### 使用提示

* 建议在项目管理工具中为每项任务创建子任务，并同步记录 KPI 数值、测试数据包与产出物链接。
* 将关键阈值写入配置或常量（例如 `CONFIDENCE_LOW=0.6`），并配套监控图表，避免仅口头约定。
* 当首次验收未达标时，需附上恢复计划（如数据增广、标签调整、模板迭代时间表）。
